# Genesis MUD C++ Client

This is an implementation of a GMCP client specifically geared toward the popular LPMud, Genesis MUD. As such, it only natively supports communication with `mud.genesismud.org` on port `3011`.

This client is under development, but is planned to support aliases and triggers with regexp functionality. The user interface will try to mirror that of the popular webclient, which can be found at `https://www.genesismud.org/play`.
